# ラウンジ背景

幅8m、奥行6m、天井高3mのワンルームです。中央にアバターを配置し、周囲にソファ・テーブル・棚を置いています。

| シーン | 照明条件 |
| --- | --- |
| `Scenes/Lounge_Baked.unity` | 室内をベイクした照明。アバター用の基準ライト1灯、ライトプローブ、ベイク済みの反射プローブを配置しています。 |
| `Scenes/Lounge_Realtime.unity` | 同じ室内・配置に、影付きのリアルタイムPoint Lightを2灯追加しています。 |

`Lounge_Baked`を中負荷、`Lounge_Realtime`を高負荷の比較条件として使えます。実際の負荷は、アバターのシェーダー・描画サイズ・端末によって変わります。

## 計測に使う

負荷検証ツールの「4. 計測環境（シーン）を登録」に、使用するシーンをProjectから登録してください。「5. 計測条件を設定して開始」で人数とカメラを選択します。

`Preset/Benchmark_Room_Baked.asset`と`Preset/Benchmark_Room_RealTime.asset`には、それぞれのシーンを登録済みです。プロファイルを自分の`Assets`内へ複製し、アバターを登録して使えます。

- 配置ピンは10本です。1人なら中央のピン、人数を増やすと後方のピンを順に使用します。
- `Camera_Main`と`Camera_Near`を登録しています。2シーンのピン・カメラは同じ位置です。
- `Benchmark Environment`の配置ピンとカメラは、シーンを開いて編集できます。
- 追加のリアルタイムライトは`Realtime Lighting`にあります。色・強さ・範囲・影をInspectorで調整できます。

## モデルと照明

モデルは27メッシュ、38,992三角形、17マテリアルです。Built-in Render PipelineのStandardシェーダーを使用しています。テクスチャは木目・布・石の色と法線の計6枚です。

室内の照明はライトマップに、動くアバターへ渡す照明は中央の125個のライトプローブに保存しています。反射プローブはベイク済みで、計測中にキューブマップを更新しません。

編集する場合は、シーンを自分の`Assets`内へ複製してください。マテリアルなどの共有アセットも変更する場合は、該当アセットを複製して参照を差し替えます。

家具やベイク用ライトを編集した場合は、照明を再ベイクしてください。リアルタイムライトだけの調整には再ベイクは不要です。

2シーンはベイクデータを共有しています。部屋を改変するときは、`Lounge_Baked`を編集・再ベイクし、その複製に`Realtime Lighting`の2灯を追加すると、背景の条件を揃えられます。
